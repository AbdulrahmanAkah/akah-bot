# Spot Speculation Bot

نظام بحث ومضاربة آلية للعملات الرقمية.

## القيود الأساسية

- Spot فقط.
- شراء الأصل ثم بيع الكمية المملوكة فقط.
- دون رافعة مالية.
- دون Margin.
- دون Futures أو Perpetuals.
- دون بيع على المكشوف.
- دون اقتراض أو فوائد.
- المضاربة فقط؛ الاستثمار طويل الأجل خارج نطاق البوت.

## الحالة الحالية

الإصدار: v0.1 Core

المرحلة الحالية:
- نماذج البيانات.
- محاسبة المحفظة.
- حساب حجم الصفقة.
- الحارس التشغيلي الشرعي.
- الاختبارات الأساسية.
