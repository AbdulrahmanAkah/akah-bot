# Package 2: source/router/execution integration, V9

## Certificate scope

This is an opt-in engineering integration, not a new strategy, market replay,
school-fidelity certificate or profit claim. Original V4–V8 files are unchanged.
V9 calls the actual native pivot/FVG/trend/breadth primitives and V8 ownership
contracts, and uses the actual V5 portfolio kernel with inherited V6/V7 mechanics.
All testing inputs are synthetic. No market/cache file is read by the runner.

The original producer-integration gap is **PARTIAL**, not fully closed: typed
semantic range/count/context proofs have to be provided by their source producer;
this package does not certify the old raw detector streams on historical markets
or automatically enumerate every valid Elliott parent/child interpretation.
Source-level synthetic proof parity is not historical producer recertification.
Independent reserve review and historical tick/lot/minimum evidence remain absent.

## Source clock and graph

`CompletedPrefix.on_close(bar, volume, now)` requires a contiguous UTC-aligned
completed stream per degree. Its actual native 2-left/2-right pivot call sees only
the five already-completed bars. The native open-stamped pivot observation and
confirmation are each converted by exactly one degree to **bar CLOSE** clocks.
Existing pivots are immutable; ties use native semantics, not a new pivot rule.

`fvg` uses the actual native three-completed-candle function. `atr` preserves
native rolling TR mean 20/minimum 10, not a newly selected ATR parameter.
`aggregate_completed` requires every hour in the canonical 4H/1D bucket.

The source graph records exact values, source SHA, availability, exclusive expiry,
parent dependencies and origin. Parent invalidation cascades. A SHA alone does
not establish doctrinal truth. `SUPPLIED_SEMANTIC_PRODUCER` claims are identified
as supplied source assertions, never promoted to verified OHLC detections.
Range branches, count objectives, PIT membership, liquidity ownership and router
phase assertions need this separate semantic provenance.

## Execution / ownership

`ContractBinding` keeps new grammar and owner IDs; it never impersonates legacy
ICT/Classical to get through old allowlists. Old enums/allowlists are untouched.
`PartialPlanV9` delegates fixed **initial** half/remaining and cost-breakeven
mechanics to V7. An existing higher stop is not lowered to cash breakeven.
The spring initial-half adapter calls the same kernel with `staged=True`; later
adds call V7 within the same original B0 and cannot reset risk or lower stops.

Native session expiry remains automatic; H2's NY16/internal MSS is diagnostic,
not an exit. H2 exits on its 4H structure or a source-bound daily reversal.
Hard protection applies before same-bar finite targets; gaps execute at the open,
not the stop. Owner pivots require two completed right bars and correct degree.
V6 earned HL/HH and consecutive-close failed-reclaim management are inherited.
Finite objectives are executable obstacles; trend objectives remain checkpoints.

The inherited kernel can reuse integer position IDs once positions close. V9
therefore resets per-position clocks, pending state, prior session endpoints and
obsolete Harmonic partial plans after a successful new fill. Integer IDs are not
lifecycle authority; immutable source/campaign IDs remain the ownership keys.
Without this reset a later unrelated thesis could inherit a previous owner's
expiry/partial management or fail on an old execution timestamp. Explicit
cross-owner sequential regression fixtures cover this integration defect.

The prebatch selector is inherited, not learned: ADD priority, ready time,
capacity, deterministic lineage tie-break. Conflicting same-asset owners reject;
no replacement of an incumbent winner is introduced. Event and envelope inputs
are hashed against mutation; parent liveness and context are rechecked at entry.
Explicit outcome fields are forbidden recursively, including decoded metadata.

## Router and authority separation

The finite phase table is a declared prospective engineering eligibility table,
not an economic regime calibration. Existing higher-timeframe/down/distribution
vetoes remain. Dow has no funded entry route. Actual-mode V9 permission **always
denies** without a later exact-version certification implementation; a supplied
boolean cannot self-certify Gate 2. `synthetic_fixture_execution=True` is visibly
separate and means only synthetic execution-mechanics tests.

Actual-mode quantity checks reject continuous numerical rules as historical
exchange evidence. New claims never alter `SchoolThesis.manifest` funding flags.
`funded_grammars=[]`, `ready_for_gate3_replay=false` throughout this package.
