# V10 four source-repair closure

Scope: new opt-in research namespace only. V4-V9 source is preserved. These
repairs are not changes to targets, sizing thresholds, school doctrine or
production. Existing explicit grammar IDs and compatible internal V9 class
names remain; namespace and producer_version are V10. Real-mode routing denies
funding until exact-version authority and independent reserve are certified.

## R1: explicit semantic stop provenance

`Produced.stop_proof` is mandatory. Each proof names unique actual live source
IDs and a typed deterministic derivation. A source graph claim names the proof
and its parents. Metadata, thesis price, graph proof and kernel binding must
agree; no `parents[0]` inference is allowed.

| Owner | Derivation | Exact source |
|---|---|---|
| ICT session | RAID_LOW | Completed raid bar low |
| H2 HTF trend | PROTECTED_LEVEL | Explicit protected higher-degree level |
| Wyckoff spring | SPRING_LOW | This campaign's completed spring low |
| Wyckoff no-spring/reaccumulation | LPS_LOW | This readiness LPS low |
| Harmonic I/II | HARMONIC_FROZEN_PROFILE_STOP | Actual XABC projection + complete preterminal traversal, unchanged V8 stop formula |
| Elliott / H3 | ELLIOTT_COMMON_PARENT_FLOOR | Live compatible counts + exact parent-floor pivots; maximum common floor |
| Classical / H1 | CLASSICAL_ACCEPTANCE_LOW or CLASSICAL_CONFIRMED_LOW | Explicit source bar or confirmed low, through the existing legacy envelope route |

H3 never borrows its location provider's stop or management. Dow stays context
only. Numeric stops and objectives retain the V8/V9 profiles. Unsupported proof
types, invalidated parents, changed metadata or price mismatch fail closed.

## R2: complete Wyckoff live dependencies

All cause/branch, range/falling pivots, supply reference/test, SOS/LPS, spring /
test / confirmation bars and volumes, PNF bars/segments/count line, market and
RS are attached to the emitted proof and recursively observed by the setup.
They are revalidated at the executable open, not only at emission. A terminated
dependency cannot be resurrected by retaining an old intent.

A source cause ID is not an execution campaign ID. The staged-add adapter now
requires an actual kernel first-fill receipt linking these IDs. Adds reuse the
initial stop binding and original B0; current LPS may only raise protection.
Wrong/missing receipts fail closed. Existing kernel prohibitions after reduction
or closure, one-add limit, asset/gross/cash/risk caps remain unchanged. An emitted
add is single-use; refusal is not permission to reset the source campaign.

## R3: prebatch feasibility

Before same-asset arbitration the pipeline calls the SAME `admit_owned` method
on an isolated copy of the actual current execution state, including fees,
normalizer, cash, held marks, risk/gross/asset caps and staged-add constraints.
Infeasible owners are excluded before they can suppress a feasible owner.
The real kernel still checks admission sequentially after arbitration. A
per-candidate prebatch PASS is NOT a guarantee all candidates fit together.
Preview cannot mutate real positions, campaigns or fills. Copying cumulative
history is correct but is not a certified large-history performance solution.

## R4: explicit Elliott scope, not invented truncation

`NONTRUNCATED_IMPULSE_PROFILE` declares the pre-existing W5-beyond-W3 requirement.
Truncated fifths are unsupported diagnostic-only inputs, not new funded counts.
The scope dispatch does not certify that every excluded shape is a valid
truncation. All ordinary geometry and parent/child constraints remain required.
This closes the hidden-scope defect; it does not implement all Elliott doctrine.

## Test and authority boundary

Tests execute real source algorithms and the actual accounting kernel on
synthetic completed prefixes. They do not read historical market rows or generate
economic outcomes. H3 is explicitly an isolated composition test, not a native
historical cross-school stream. Wyckoff range/branch authority and Elliott
recursive proof are supplied semantic inputs, not newly proven automatic
historical phase/count generation. Classical/H1 retain their existing source
envelope; this is not a new full-pattern fidelity certificate.

Real current-version market reserve preparation remains blocked until those
upstream producers yield exact-version certified causal cases. The old 98
primary and 90 reserve cases are excluded; their old charts cannot certify V10.
No synthetic examples are substituted for a fresh market-fidelity reserve.
