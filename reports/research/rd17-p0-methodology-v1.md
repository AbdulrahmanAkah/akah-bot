# RD17-P0 Universe Protocol and Manual Rank Verification

## Purpose

Validate the historical ranking methodology before any RD17 signal generation
or portfolio replay.

## Primary universe

Top-6 is retained as the primary reference only as a direct comparison anchor
to RD16 and the registered portfolio-capacity architecture. It is not treated as
a universally optimal number. Top-4, Top-8, and Top-10 are pre-registered
structural sensitivities.

## Timing

A decision on day D may use only information available from day D-1. The manual
check uses four Sunday market-cap snapshots and compares them with the Monday
rebalance rows generated by the Coin Metrics panel.

## Independent source

CoinMarketCap historical snapshots are frozen into
`independent-cmc-snapshots.csv`. The runner does not access the network.
Stablecoins, wrapped assets, and duplicate network representations are removed
using the same canonical exclusion rules as the project panel.

## Pass conditions

A clean pass requires exact Top-6 set agreement at all four snapshots, one-day
timing alignment, contiguous local ranks, positive USD market caps, rank
displacement no greater than two for common symbols, and market-cap ratios that
exclude unit-scale errors.

A source-difference pass allows one-symbol disagreement per snapshot while
preserving all timing, unit, and rank-integrity gates. Anything weaker rejects
the methodology and blocks RD17-P1.

## Boundaries

This phase performs no signal generation, optimization, trading replay,
production authorization, or access to 2025/2026 data.
